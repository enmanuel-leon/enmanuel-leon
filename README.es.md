- **Arquitectura Agéntica & Orquestación:** Colaboración en el diseño e implementación de arquitecturas agénticas multi-agente, flujos de ejecución autónomos, tool calling y comunicación M2M de baja latencia mediante APIs desacopladas y autenticación basada en tokens.
- **Procesamiento Asíncrono & Generación de Artefactos:** Construcción de motores distribuidos de alta concurrencia para generación de documentos y artefactos con BullMQ, Redis, Fastify y Python, orquestando background workers y crons distribuidos programados.

- **Infraestructura Cloud, Aislamiento VPC & Seguridad:** Operación de microservicios de alta disponibilidad en AWS y GCP en contenedores Docker, con sincronización M2M segura entre VPCs aisladas y control de acceso granular mediante Row-Level Security (RLS) para proteger contratos y registros financieros.
